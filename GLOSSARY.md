#   Debug glossary

*   **Entry**: one diagnostic message and its severity, label, optional value or exception, and creation time.
*   **Debugger / output target**: a recipient that presents or forwards a diagnostic entry.
*   **Formatter**: the rule that turns an entry into readable text.
*   **Facade**: the shared convenient entry point that delegates to a configured service.
*   **Label**: the grouping name or caller origin attached to an entry.
